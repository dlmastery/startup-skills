## Exit criteria: Discovery → Validation (all numeric, all pre-declared; sources in experiment_board.md)

Gate opens only when **all five** hold:

1. **Trust test passed (E1):** ≥5/15 practitioners reproduce a bundle unaided with one command AND ≥3/15 run their own private data AND ≥8/15 name specific deploy-evidence (gtm §4 / BRIEF thresholds, unchanged).
2. **Proof artifact honest (E2 + E6):** DSR + CPCV published for the lead bundle with the true trial count (or the fresh-instrumented-run substitute, positioning §4.2), and gate catch-rates measured on seeded violations (≥90% deterministic-class catch, ≤10% false positives).
3. **Paying customers: ≥150 paying individuals ≈ $225k ARR run-rate** (market_sizing §5 — the corrected year-1 beachhead number; the strategy layer's committed target, requiring ~1.6% of the ~9.5k mid-band active base, inside the [C32] 1–5% norm).
4. **Kill triggers not fired at the measured-active checkpoint (market_sizing §6):** paid conversion ≥0.5% of measured active users AND active base >3,000 at month 6 of maintained-successor work. Firing either does not advance the stage — it escalates A2 to the ASSUMPTIONS.md protocol.
5. **Discovery interviews done:** ≥20 synthesized interviews across cards 1–4 per discovery_guide.md, with must-have-language tallies confirming (or correcting) the value-prop #1 mapping.

Interim sub-gate inside Discovery (already scheduled): day-61 **$99 pre-order gate** opens only on E1 pass; 30 pre-orders + 5 design partners (E4) is the first money-based evidence, at ~5% of a hosted build's cost (gtm §4 step 7).
