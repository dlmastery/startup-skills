# D05 — Model Routing & Cost Control (BYOK)

The product's token economics (A12: BYOK-first; tokens are user-side). The PoC ran a single Claude-family assistant; the routing layer is the productization, priced at real Aug 2026 list prices [B18][B19][B20].

```mermaid
flowchart TD
    STEP["Loop step to execute"] --> CLASS{"Step class? [planned router]"}

    CLASS -->|"Diagnose / Hypothesize /<br/>stall self-reflection"| FRONT["Frontier-reasoning tier<br/>Sonnet 5 $2-3 in / $10-15 out per Mtok<br/>gpt-5.6-terra $2 / $12"]
    CLASS -->|"Execute scaffolding / log parsing /<br/>Document / Checkpoint"| MID["Routine tier<br/>Haiku 4.5 $1 / $5<br/>Gemini 3.7 Flash $0.75 / $3.75<br/>gpt-5.6-luna $0.20 / $1.20"]
    CLASS -->|"Literature fetch + summarize<br/>cacheable, batchable"| BULK["Bulk tier + caching<br/>cache hits at 10 percent of input price<br/>batch minus 50 percent"]

    KEYS["User's own API keys - BYOK [planned]<br/>Anthropic / OpenAI / Google / local endpoint"] --> FRONT
    KEYS --> MID
    KEYS --> BULK

    FRONT --> TELE
    MID --> TELE
    BULK --> TELE

    TELE["Per-step cost telemetry<br/>written to run record [planned]"] --> GOV{"Daily budget governor<br/>user-set, e.g. $10/day [planned]"}
    GOV -->|under budget| CONT["Continue campaign"]
    GOV -->|breach| DEGRADE["Graceful degradation:<br/>route routine steps one tier down,<br/>lengthen experiment interval,<br/>alert dashboard - never silent halt"]
    ESC["Gate failure or low-confidence output"] -->|re-run one tier UP, logged| FRONT
```

**What a reviewer should notice:** (1) the split is by *step class*, and the frontier slice is deliberately thin — the arithmetic that makes a 24/7 campaign $3–12/day mid-tier-routed vs $20–60/day all-frontier (capability_table §3) is this diagram; (2) escalation runs upward on failure and is logged, so cheap-model errors cost one retry, not silent quality loss; (3) BYOK means Ascent's Pro margin carries zero token COGS by construction (A12) and the user's spend rides the 40–50x/yr capability-cost decline [B16] while frontier list prices rise [B19][B21]; (4) the constitution is what makes models swappable (A9) — behavior is pinned by the protocol file, not by one vendor's prompt quirks.
