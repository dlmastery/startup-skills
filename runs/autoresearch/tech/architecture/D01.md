# D01 — Experiment Data Pipeline

From raw dataset to append-only evidence, as implemented in `core/runner.py` (one experiment per invocation).

```mermaid
flowchart TD
    CFG["config.yaml / CLI flags<br/>backbone, split, metric, seed, description [exists]"] --> RUN
    DATA["Dataset loader<br/>csv / parquet / numpy / sklearn [exists]"] --> RUN
    ANN["Pre-run reasoning annotation<br/>reasoning_annotations.json [exists]"] --> GATES

    subgraph GATES["Pre-flight gates - refuse to launch on failure [exists]"]
        G2["Gate 2: citation rigor validator"]
        G3["Gate 3: reasoning completeness validator"]
        G1["Gate 1: split overlap assertion + GPU pre-flight"]
    end

    RUN["core/runner.py"] --> GATES
    GATES -->|all pass| SPLIT["Splitter registry<br/>super_fold / walk_forward / kfold ...<br/>purge + embargo buffers [exists]"]
    GATES -->|any fail| REFUSE["Refused: no compute spent,<br/>no ledger row written [exists]"]

    SPLIT --> SCALE["Standard scaling<br/>fit on train only [exists]"]
    SCALE --> BB["Backbone via registry<br/>MLP / LSTM / Transformer / XGB / LGBM / CatBoost [exists]"]
    BB --> PRED["predict_with_uncertainty<br/>MC dropout / ensembles / quantiles [exists]"]
    PRED --> MET["Metric registry + composite calculator<br/>SHA-256 formula fingerprint [exists]"]

    MET --> LOG["experiment_log.jsonl - append only<br/>every trial incl. discards [exists]"]
    MET --> PLOG["trade_logs/expN_predictions.csv<br/>+ prediction_summary.json [exists]"]
    MET -->|new global champion only| CHAMP["best_config.json + best_model.pt<br/>then winner archive [exists]"]
```

**What a reviewer should notice:** (1) the gates sit *before* the splitter — an experiment that fails citation or reasoning validation costs a refusal message, not compute, and never appears in the ledger as a "run"; (2) the ledger is append-only and records discards, which is the raw material for the trial-count-corrected acceptance gate (deep_dives §4) and the private corpus (A11); (3) scaling is fit on train only — the leakage discipline extends below the split level; (4) champion artifacts are written by exactly one code path, so "champion" has a single, auditable definition.
