# D04 — Durable Run Record & Calibration-Corpus Schema

The data model that makes a campaign auditable — and the A11 boundary: what ships in public bundles vs what accumulates privately as the moat.

```mermaid
erDiagram
    CAMPAIGN ||--o{ EXPERIMENT : "runs 1..N"
    CAMPAIGN ||--|| CONSTITUTION : "bound by"
    CAMPAIGN ||--o{ STEERING_EVENT : "receives"
    EXPERIMENT ||--|| REASONING_ENTRY : "requires pre-run"
    EXPERIMENT ||--o{ GATE_RESULT : "passes or fails 3"
    EXPERIMENT ||--o| CHAMPION : "promotes to 0..1"
    CHAMPION ||--|| WINNER_BUNDLE : "archived as"
    EXPERIMENT }o--|| TRIAL_LEDGER : "appended to"
    TRIAL_LEDGER ||--o| DSR_ATTESTATION : "deflates via planned"
    GATE_RESULT }o--o| CALIBRATION_CORPUS : "feeds private"
    TRIAL_LEDGER }o--o| CALIBRATION_CORPUS : "feeds private"

    CAMPAIGN {
        string campaign_id
        string dataset_hash
        string metric_name
        string composite_fingerprint "SHA-256, frozen"
        string constitution_version
    }
    EXPERIMENT {
        int experiment_num
        string backbone
        json config
        int seed
        float composite
        float val_primary
        float test_primary
        json per_fold_results
        string verdict "KEEP DISCARD NEAR-MISS"
        float seconds_elapsed
        string git_commit
    }
    REASONING_ENTRY {
        string diagnosis "floor 60 words"
        string citations "6 required elements"
        string hypothesis "mechanism clause required"
        string prediction "quantitative"
        string verdict
        string learning "axis closed or open"
    }
    GATE_RESULT {
        string gate_name "integrity citation reasoning"
        bool passed
        json violations
    }
    WINNER_BUNDLE {
        string readme
        json config
        blob model_checkpoint
        blob code_snapshot
        string audit_report_14_sections
        string reproduce_log
        blob colab_notebook
    }
    TRIAL_LEDGER {
        int n_trials_total "includes discards"
        string ledger_hash_chain "planned attestation"
    }
    CALIBRATION_CORPUS {
        json discarded_trial_stats "never ships"
        json gate_catch_rates "seeded violations, planned"
        json what_worked_where_priors "cross-domain, never ships"
    }
    DSR_ATTESTATION {
        float raw_metric
        float deflated_metric "planned"
        int trial_count
    }
```

**What a reviewer should notice:** (1) every entity except two exists in the PoC today as concrete files (`experiment_log.jsonl`, `reasoning_annotations.json`, `winners/`, checkpoint markdown) — the planned entities are exactly the DSR attestation and the calibration corpus aggregates; (2) the **A11 boundary**: WINNER_BUNDLE ships publicly (champions + run logs + audit reports); TRIAL_LEDGER discard statistics, gate catch-rates, and what-worked-where priors never ship — bundles carry the positive result and its evidence, the corpus keeps the negative space a fork cannot backfill; (3) the ledger's planned hash chain makes *omitting* a discarded trial detectable — the property a trustworthy deflated Sharpe requires; (4) the composite fingerprint lives at campaign scope: one frozen formula per campaign, by construction.
