# D08 — Observability, Evaluation & Safety Monitoring

What the system watches about itself. The raw signals all exist in today's logs; the monitors that consume them are the productization. This diagram is the answer to "who audits the auditor."

```mermaid
flowchart TD
    subgraph SIGNALS["Raw signals [exists in logs today]"]
        LG["Ledger rows: composite, per-fold,<br/>seed, runtime, verdict"]
        GV["Gate violation lists per experiment"]
        CK["Checkpoint cadence + crash markers"]
        ST["Steering log entries"]
    end

    subgraph MON["Monitors [planned]"]
        M1["Gate telemetry:<br/>pass/fail rates per gate over time;<br/>drift = constitution erosion signal"]
        M2["Seed-variance tracker:<br/>champion re-run at K seeds;<br/>flag if delta within noise band"]
        M3["Proxy-divergence watch:<br/>composite vs each raw target metric;<br/>Goodhart onset = divergence trend"]
        M4["Trial-count meter:<br/>N total incl. discards, effective N,<br/>current deflated threshold"]
        M5["Reproduction telemetry:<br/>bundle rerun pass/fail<br/>on user machines opting in"]
        M6["Stall score:<br/>K experiments since champion +<br/>marginal-delta slope"]
    end

    subgraph ACT["Actions"]
        A1["Dashboard panels + alerts [partial:<br/>dashboard exists, panels planned]"]
        A2["Auto-escalate: NEAR-MISS class,<br/>demand more seeds before KEEP [planned]"]
        A3["Campaign halt on integrity violation:<br/>discard + full log [exists as runner refusal]"]
        A4["Suggested steering prompt<br/>surfaced to human [planned]"]
    end

    LG --> M2
    LG --> M3
    LG --> M4
    LG --> M6
    GV --> M1
    CK --> M1

    M1 --> A1
    M2 --> A2

```

**What a reviewer should notice:** (1) M3 is the direct answer to the strongest theoretical critique — Goodhart's threshold effect [D31]: fingerprinting froze the proxy, this monitor watches whether the frozen proxy is drifting from the raw targets it summarizes; (2) M2 and M4 operationalize the two statistical exposures the survey names (seed-luck accumulation [D11][D12], max-of-N selection [D6][D7]) as running gauges, not one-time caveats; (3) M5 is the trust flywheel instrumented: every opted-in bundle rerun is third-party reproduction telemetry — the metric the whole company's riskiest assumption hangs on; (4) no monitor here requires new data collection — the PoC's ledger already carries every input field, which is why this layer is buildable this quarter (not_vaporware.md).
