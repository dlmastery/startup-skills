Ascent · V10 · Audience: VC

Ninety days of scripted motion end in pre-orders, not a hosted fantasy

The sequence is deliberate: earn standing before running the trust test, run the trust test before selling anything, and open a paid signal without building the hosted product. Each phase has a gate that can stop the next one.
DAYS 1–30
Earn standing in the community
  • Ship ascent v0: the constitution + gates running the original task, leakage-safe splits, fingerprints — upstream-credited
  • Answer the top ~15 upstream issues substantively — full answers in-thread, zero link-drops
  • Post the bridge write-up: "what 16 notable forks built, and the layer none of them did"
  • Instrument the funnel to measure active users (cloned + ran within 90 days), not stars
DAYS 31–60
Run the trust test before selling anything
  • 15-practitioner test; at least 3 run Ascent on their own private dataset — the contamination-proof leg
  • Recruit ~40 candidates to yield 15 at a ~40% show rate; outreach weeks 5–7, sessions weeks 7–10
  • Incentive is lifetime Pro + named acknowledgment — no cash, which keeps the cohort credibility-selected
  • Publish results with the self-deflation treatment and put the acceptance gate on the roadmap
DAYS 61–90
Open a paid signal, not a hosted build
  • No hosted-Pro build. Instead: $99 pre-orders and design-partner commitments against the BYOK CLI
  • Target 30 pre-orders and 5 design partners — the same conversion evidence at ~5% of the cost
  • Hosted dashboards get built only after pre-orders clear the gate
  • First 10 customers named by type; first 100 through the champion loop — 30 published bundles, ≥3 reproductions each, by day 180
Zone 4 — Founder capacity, weeks 1–12 (solo, 55 hrs/wk)
WorkstreamHrs/wk
ascent v0 + BYOK CLI packaging15
Community: issue answers, fork upkeep15
Trust test: recruiting, sessions, write-up10
Bundles + DSR computation + posts10
Admin / entity / misc5
If over capacity, the pre-order gate slips first. Paid-signal work is deferred before community work — the channel decays without maintenance, which is exactly how the comparable project died — and never at the expense of the trust test, which gates everything downstream.
Zone 5 — The gates that can stop the plan
Trust-test gate: if fewer than 5 of 15 practitioners reproduce, stop the paid path and fix the proof artifact — not the marketing.
Conversion gate: if paid conversion is <0.5% of measured active users by month 6, the core assumption is wrong — rework GTM and financials rather than pushing harder.
Fork etiquette, binding before day 1: the successor is separately named, upstream credit is prominent everywhere, and the original author gets a private heads-up before launch. If he returns or blesses a different fork: congratulate publicly, keep compatibility, shift to the plan-B channel.
