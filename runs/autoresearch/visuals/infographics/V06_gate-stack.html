Ascent · V06 · Audience: cross

A constitution enforces what a tired human skips

Three programmatic checks run before any commit. They are not linting and not advice: an experiment that fails a gate does not enter the champion line at all. Refusal is the default state.
Zone 1 — The 7-step method, enforced on every experiment
Diagnose→ Literature-ground→ Hypothesize→ Execute→ Analyze→ Document→ Checkpoint
Codified in a binding 52-section constitution — the encoded research judgment that is the product's core IP, and the thing a fork can copy in a day but cannot have refined across domains.
GATE 1
Data integrity
Purged and embargoed super-folds; train = data − union(val + test + buffers). Temporal and overlap leakage are made structurally impossible, not merely checked for.
GATE 2
Citation rigor
Every hypothesis must be literature-grounded before compute is spent. A refused experiment costs a message, not a GPU-hour.
GATE 3
Reasoning completeness
The reasoning trace must be present and complete before a result may be written. The agent may not, by contract, write a result row — the runner writes what actually happened.
Zone 3 — The ablation: what the gates are worth
+42% invalid experiments
when the citation gate was removed — plus 3 leakage incidents that the gated arm did not produce. The rigor layer measurably pays for its own overhead.
Founder-reported, one task, one seed. This is a real experiment with a real ledger, not a benchmark claim — and it is single-seed, so it is stated as directional evidence, not a measured effect size.
Zone 4 — No silent path around the machinery
Refusal by default. There is exactly one bypass, it is visible, and it writes a sentinel tag into the run log. An auditor grepping for the sentinel finds every experiment that ever went around a gate. There is no quiet override, no debug flag, no "just this once."
Safety and metric-integrity branches structurally outrank progress branches in the decision tree — the agent cannot trade rigor for a better number, because the ordering is not the agent's to choose.
Zone 5 — The claim, scoped exactly
The gates make keep-or-discard tamper-evident, not tamper-refusing — refusal is [ROADMAP], a ~15-line patch. And "monotonic" always means monotonic in the composite proxy: a ratchet guarantees monotonicity in the proxy, not in the truth.
