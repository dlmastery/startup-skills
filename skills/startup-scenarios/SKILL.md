# startup-scenarios

## Three files

1. `LOW_END.md` — `{spectrum.low_end}`. Dignity-preserving onboarding in the first 8–12 minutes. Precise diagnosis of hidden threats. Dual path (repair + accelerate) if the domain has both. Multi-way delivery. Rapid feedback. Evidence and handoff to the buyer.
2. `BEACHHEAD.md` — the specific beachhead persona from `params.beachhead` and the matching `personas` id. Same six phases, more concrete.
3. `HIGH_END.md` — `{spectrum.high_end}`. Same structure, raised demand, far-transfer, no busywork.

## Phase skeleton (every scenario)

1. Zero-to-safe onboarding
2. Precise diagnosis
3. Personalized planning (dual path if the domain has repair + accelerate)
4. Multi-way delivery
5. Rapid feedback and confidence/trust shift
6. Evidence and continuity

Write under `05_scenarios/`. Images `P04`, `P05` come later.
